개인정보처리방침

바로샷 (BaroShot) · 시행일 2026년 11월 18일

바로샷(이하 “앱”)은 업무 사진을 목적별로 찍어 휴대폰에 보관하고, 사용자가 고른 곳(회사 PC, 갤러리, 카카오톡, 메시지, 이메일 등)으로 보내는 앱입니다. 앱은 회원가입이 없고, 이름·전화번호·이메일 같은 개인정보를 수집하지 않습니다.

1. 앱이 다루는 정보와 보관 위치

찍은 사진·동영상, 목적 이름사용자의 휴대폰 안(브라우저 저장 공간)에만 저장됩니다. 운영자의 서버로 자동 전송되지 않으며, 운영자는 볼 수 없습니다.
회사 PC 연결 정보휴대폰과 PC를 연결하는 무작위 연결 코드(64자리)가 각 기기 안에만 저장됩니다.
앱 설정마지막으로 고른 목적, 보기 방식 등이 휴대폰 안에만 저장됩니다.

2. 사용하는 권한

카메라사진·동영상 촬영, 회사 PC 연결용 QR 코드 읽기
마이크동영상을 찍을 때 소리 녹음 (허용하지 않으면 소리 없이 녹화)
파일 저장(다운로드)“갤러리”를 눌렀을 때 사진을 휴대폰의 다운로드 폴더에 저장
폴더 접근 (PC 받기)회사 PC에서 사용자가 직접 고른 저장 폴더에만 사진을 저장

3. 외부로 전달되는 경우

사용자가 직접 보내기를 누를 때만 전달됩니다.

  • 회사 PC로 보내기: 고른 사진·동영상과 파일 이름, 목적 이름이 Google Firebase(Cloud Firestore, 서울 지역)를 잠시 거쳐 사용자가 연결한 PC로 전달됩니다. PC가 저장하는 즉시 Firebase에서 삭제됩니다. PC 받기가 꺼져 있으면 다음에 켜서 받을 때까지 보관됩니다. 연결 코드를 아는 휴대폰·PC만 그 자료에 접근할 수 있습니다.
  • 카카오톡·메시지·이메일·다른 앱: 휴대폰의 공유 기능으로 사용자가 고른 앱에 직접 전달됩니다. 이후 처리는 해당 앱의 정책을 따릅니다.
  • 갤러리: 사용자 휴대폰 안에만 저장됩니다.

앱은 광고, 사용 통계 분석, 위치 정보 수집, 쿠키를 사용하지 않습니다.

4. 보관 기간과 삭제

  • 휴대폰 안의 사진·동영상은 사용자가 앱에서 지우거나, 브라우저(크롬)의 사이트 데이터를 지울 때까지 보관됩니다.
  • 회사 PC로 보낼 때 Firebase를 거치는 자료는 PC가 받는 즉시 삭제됩니다.
  • 회사 PC에 저장된 파일은 사용자가 PC에서 직접 관리합니다.

5. 아동의 개인정보

앱은 업무용으로 만들어졌으며 만 14세 미만 아동을 대상으로 하지 않습니다.
