# 업무 사진

목적별로 업무 사진·동영상을 찍고, **회사 PC(목적별 폴더)**·갤러리·카카오톡·메시지·이메일·다른 앱으로 보내는 휴대폰용 웹앱이에요.
회사 PC에는 **PC 받기** 화면을 설치해 두면, 보낸 사진이 PC 폴더 안에 목적 이름 폴더로 저장돼요.

- 휴대폰 앱: https://gkak00940-netizen.github.io/camaraapp/
- PC 받기: https://gkak00940-netizen.github.io/camaraapp/pc.html

## 처음 한 번
1. **휴대폰**: 꼭 **크롬**에서 앱 주소를 열고 **앱 설치**. (삼성 인터넷·카톡 안에서 열면 맨 위에 "크롬으로 열어 주세요" 경고가 나와요)
2. **회사 PC**: 크롬(또는 엣지)에서 PC 받기를 열어 설치 → ① 저장할 폴더 고르기.
3. **연결**: 휴대폰 앱의 **🖥 회사 PC 연결 → 연결하기**로 PC 화면의 QR을 비추면 끝. (QR이 안 되면 "연결 주소 붙여넣기")

## 휴대폰 앱
- **촬영 목적**: 맨 위 상자를 누르면 목록이 펼쳐져요. 입력하면 새 목적. 목적 폴더의 **✎ 이름**으로 이름 바꾸기.
- **찍기**: 검은 칸을 누르면 폰 화면 전체 카메라. **사진 | 동영상** 전환, 동영상은 소리 포함 최대 5분(720p, 1분 약 19MB).
- **사진 보관함**: 목적별 폴더 / 날짜별 보기. 사진 위에 **받음**, **✓PC·카톡**(보낸 곳) 표시.
- **크게 보기**: 사진을 누르면 갤러리처럼 화면 전체. 옆으로 밀어 넘기기, 두 번 톡 확대, 그 자리에서 **선택·보내기·삭제**.
- **고르기**: 사진 왼쪽 위 네모 → 아래 한 줄 바. 여러 목적 폴더를 오가며 최대 20개.
- **보내기** (3칸 2줄): **회사 PC**(목적별 폴더로 저장) · **갤러리**(다운로드 앨범) · **카카오톡** / **메시지** · **이메일** · **다른 앱**(드라이브·퀵쉐어 등)
- **받은 사진 넣기**: "＋ 받은 사진·영상 가져오기" 또는 다른 앱에서 공유 → 업무 사진.

## PC 받기
- 휴대폰에서 보낸 사진이 `저장폴더\목적 이름\파일`로 저장돼요. 꺼져 있을 때 보낸 것은 다음에 켜면 들어와요.
- **③ 받은 사진 · 목적별**: 저장 폴더 안을 목적별 폴더로 보여 줘요. 날짜별로 펼치기, 크게 보기·영상 재생.
- 목록이 길어지면 **🧹 목록 비우기** / 폴더별 **✕ 빼기** (목록에서만 빠지고 파일은 그대로), **숨긴 것 다시 보기**.

## 용량 기준 (고르면 바에 합계와 추천이 나와요)
| 보내는 곳 | 기준 |
|---|---|
| 메시지(문자) | 약 1MB 안팎 → 사진 몇 장만, 동영상은 못 보내요 |
| 이메일 | 25MB까지 (Gmail은 넘으면 드라이브 링크) |
| 카카오톡 | 사진·짧은 영상. 사진과 영상을 섞으면 '파일'로 가서 따로 보내라고 안내해요 |
| 회사 PC · 갤러리 · 드라이브 | 크기 걱정 없음 (100MB 넘으면 와이파이에서) |

## 파일
| 파일 | 하는 일 |
|---|---|
| `index.html`, `app.js`, `style.css` | 휴대폰 앱 |
| `pc.html`, `pc.js`, `pc.css` | PC 받기 |
| `relay.js` | 휴대폰 → PC 중계 (Firebase Firestore, 받으면 바로 지움) |
| `config.js` | Firebase 설정값 (공개돼도 되는 주소 정보) |
| `firestore.rules`, `FIREBASE-설정.md` | 보안 규칙과 처음 설정하는 법 |
| `sw.js`, `manifest*.webmanifest`, `icons/` | 설치·오프라인·공유 받기·아이콘 |

## 고칠 때
- `sw.js`의 `work-photo-app-v25` 숫자와 `index.html`·`pc.html`의 `?v=25`을 함께 1씩 올려야 설치된 휴대폰·PC가 새 화면을 받아요.
- 사진은 휴대폰 크롬 안(이 앱 보관함)에만 있어요. 크롬 데이터를 지우면 사라지니 중요한 사진은 바로 보내 두세요.
