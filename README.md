# 업무 사진

목적별로 업무 사진을 찍고 구글 드라이브·카카오톡·이메일·문자·다른 앱으로 보내는 휴대폰용 웹앱입니다.

## 쓰는 법
1. 맨 위 **촬영 목적** 상자를 누르면 저장한 목적 목록이 아래로 펼쳐져요. 눌러서 고르세요.
   새 목적은 상자에 입력하고 완료(엔터) 또는 목록의 "＋ 새 목적으로 추가"를 눌러요. 목록 오른쪽 ✎로 이름을 바꾸고, ×로 지울 수 있어요.
   (목적 폴더를 펼쳐 "✎ 이름"으로도 바꿀 수 있어요. 사진은 그대로예요.)
2. 검은 칸을 누르면 카메라가 폰 화면 전체로 열려요. 화면이나 둥근 버튼을 누르면 찍히고, 지금 고른 목적에 저장돼요. ✕ 또는 휴대폰 뒤로 가기로 닫아요.
   **동영상**: 카메라 아래 "사진 | 동영상"에서 동영상을 고르고 빨간 버튼으로 녹화 시작·멈춤. 소리도 함께 녹음돼요(처음에 마이크 허락).
   720p로 1분에 약 19MB, 한 번에 최대 5분(약 95MB)까지 찍혀요.

## 용량 기준 (보내기 전에 선택 바에 합계와 추천이 나와요)
| 보내는 곳 | 기준 |
|---|---|
| 문자(MMS) | 약 1MB 안팎 → 사진 몇 장만. 동영상은 못 보내요 |
| 이메일 | 25MB까지 첨부 (Gmail은 넘으면 드라이브 링크로 바뀜) |
| 카카오톡 | 사진·짧은 영상 OK. 큰 영상은 화질이 줄 수 있어요 |
| 구글 드라이브 | 크기 걱정 없음 (드라이브 남은 공간만큼) |
| 회사 PC | 크기 걱정 없음. 100MB 넘으면 와이파이에서 보내기 권장 |
3. **사진 보관함**에서 찍은 사진을 확인해요.
   - **목적별**: 목적마다 폴더로 묶여 장수·촬영 날짜·미리보기가 보여요. 누르면 날짜별로 펼쳐져요. 폴더에서 "이 목적 선택", "이 목적으로 찍기"를 할 수 있어요.
   - **날짜별**: 모든 사진이 날짜순(오늘·어제·n일 전)으로 나오고, 사진마다 어느 목적인지 이름과 색이 붙어요.
4. 사진 왼쪽 위 네모를 체크하면 화면 아래에 **보내기·삭제 바**가 바로 나와요.
   드라이브 / 카카오톡 / 이메일 / 문자 / 다른 앱 중 하나를 누르면 휴대폰 공유 화면이 열려요. 위에 나오는 안내대로 앱을 골라요.
   보낸 뒤 받은 것을 확인하면 같은 바의 **삭제**로 휴대폰 공간을 비워요.

## 받은 사진 넣기
- **받은 사진 가져오기** (사진 보관함 맨 위) 또는 목적 폴더 안 **＋ 가져오기**: 갤러리에서 사진을 고르고, 넣을 목적을 골라요(새 목적도 가능). 카톡에서 받은 사진은 먼저 "저장"해 두면 갤러리에 있어요.
- **다른 앱에서 바로 보내기** (앱을 홈 화면에 설치한 경우): 카카오톡·갤러리에서 사진 → 공유 → **업무 사진**을 고르면 앱이 열리고 넣을 목적을 물어봐요.
- 받은 사진에는 "받음" 표시가 붙고, 큰 사진은 찍은 사진과 같은 크기로 줄여서 저장해요.

## 휴대폰에 설치
갤럭시 크롬에서 앱 주소를 열고 **앱 설치** 버튼(또는 ⋮ 메뉴 → 홈 화면에 추가)을 누르면 홈 화면에 아이콘이 생겨요.

## 사무실 PC로 옮기기
- **구글 드라이브** (밖에서도): PC에 Google Drive 데스크톱을 설치해 두면 드라이브로 보낸 사진이 PC 폴더에 자동으로 들어와요.
- **카카오톡**: 회사 단톡방이나 나와의 채팅으로 보내고 PC 카카오톡에서 저장해요.
- **퀵 쉐어** (같은 와이파이): PC에 Quick Share를 설치하고 **다른 앱**으로 보내요.
- **이메일**: 제목과 목적별 촬영 시각이 자동으로 들어가요. 보낸 사진 파일 이름에는 목적 이름이 붙어요.

## 알아 두기
- 사진은 이 휴대폰의 크롬 안에만 저장돼요(갤러리에는 없음). 크롬 데이터를 지우면 사라지니 중요한 사진은 바로 보내 두세요.
- 앱 파일을 고치면 `sw.js`의 `work-photo-app-v12` 숫자와 index.html·pc.html의 `?v=` 숫자를 함께 올려 주세요. 그래야 설치된 휴대폰이 새 화면을 받아요.

## 파일
- `index.html`, `style.css`, `app.js`: 화면과 기능
- `manifest.webmanifest`, `icons/`: 앱 이름과 아이콘
- `sw.js`: 인터넷이 약해도 앱이 열리게 하는 파일

## 회사 PC로 보내기 (목적별 폴더로 저장)
- 처음 한 번: `FIREBASE-설정.md` 대로 중계 저장소를 만들고 `config.js`에 설정값을 넣어요.
- 회사 PC 크롬에서 `pc.html`(PC 받기)을 열어 설치 → ① 저장할 폴더 고르기 ② 휴대폰 카메라로 QR 찍어 연결.
- 휴대폰: 사진을 고르고 보내기 칸의 **회사 PC로 보내기** → PC의 `고른 폴더/목적 이름/` 안에 저장돼요. 보낸 사진에는 "PC✓" 표시가 붙어요.
- PC 받기 앱이 꺼져 있을 때 보낸 사진은 다음에 켜면 저장돼요. 저장되면 중계 저장소에서 바로 지워져요.
